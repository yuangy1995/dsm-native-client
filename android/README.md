# Android 原生客户端

Android 客户端使用 Kotlin、Jetpack Compose、Coroutines、OkHttp 和 Android Keystore。
当前 `applicationId` 为 `io.github.qwertyuiop1995.dsmnativeclient`，最低 Android 版本为
API 29；这些标识和最低版本不是本轮修改范围。

当前按[用户确认的 UI](../docs/design/ANDROID_UI_SPEC_ZH.md)与
[重写计划](../docs/development/ANDROID_CLIENT_COMPLETION_PLAN_ZH.md)完成A0—A10批准源码范围与本机收口，最终Debug测试包已生成。真实NAS、物理设备和完整云端门禁仍待验。原 Logo 保留，
首页模块增加显示/隐藏自定义。登录和恢复已读取账号应用授权，Photos 独立授权；
业务请求、Worker 与跨 NAS 在发送前检查所属账号授权。返回前台、手动刷新与明确拒绝会更新权限，
撤销时清除展示缓存、停止相关读取并保留已提交操作的结果记录；导航过滤不修改用户偏好。
多 NAS/同 NAS 多账号已使用独立会话与页面，切换保留原目录；单独退出、重命名与缓存清理按账号隔离。
旧任务归属不可证明时保留并暂停，改账号或地址不会自动接管旧任务。
API 37 局域网按需授权已接入，拒绝后保留会话，权限/证书错误停止 QuickConnect 回退。
任务中心已汇总所有连接的本机记录，通知与新复制的页面链接绑定原账号；查看历史不自动登录。
文件上传认证已移出网址，保留请求头与正文认证。上传中断和备份同名文件通过实际内容判断，
不确定任务不重发；任务卡片可打开原目录。文件页新增多目录、高级条件和正文搜索，
等待完整结果并说明未覆盖位置；名称支持 `/表达式/` 和忽略大小写的 `/表达式/i`，
正文搜索仍使用普通关键词。文件夹上传保留所选根目录和空目录，上传前预览清单，
默认保留同名文件，可明确确认替换；任务详情展示每项结果，取消保留已上传内容，
中断后不重复发送结果不明的文件。文件夹或多个所选项目可保存成一份 ZIP，系统选择保存位置，
任务中心支持暂停、继续和取消；ZIP 继续时重新下载，普通单文件仍可续传。
恢复使用原文件清单与原账号，无法恢复清单时提示重新选择。
分享支持单项或多选创建、开始与到期日期、密码设置与移除、指定用户/群组、访问次数和文件夹收集。
共享链接可搜索、批量编辑或删除，并提供复制、系统分享与本地二维码。中断后只读取原链接结果，
不保存分享密码、不自动重发创建；未返回明确链接编号时不会按同名文件认领结果。
压缩包可浏览内部文件夹、加载更多并选择内容，支持目标位置、密码和文件名语言；
可保留目录结构、新建同名文件夹，替换已有文件时单独确认。压缩可选择速度或体积优先，
用户输入的名称保留点号。任务中断后只读原任务，覆盖结果不会因旧文件存在而误报成功。
文件菜单可查看和修改所有者与访问权限，支持账号/群组、细分操作与文件夹子项范围。
继承权限、共享根目录、回收站和挂载位置保持只读；保存前显示具体变化，阻止使当前账号失去访问的修改。
连接中断、页面关闭或重启后可刷新原操作结果，不重复保存；部分项目修改失败时会明确提示。
文件、Photos、Chat、下载、NAS/套件、容器/VMM与系统入口的批准源码范围已接入；
真实NAS、物理设备及云端完整门禁仍按计划分别验收。
配套目标为 Java 25、Gradle 9.6.1、AGP 9.4.1、内置 Kotlin 2.2.10、Compose BOM 2026.09.00、
WorkManager 2.12.0 和 Android API 37，Java/Kotlin 字节码仍为 17；实际验证以状态页为准。
二维码使用已批准的 ZXing Core 3.5.4，离线生成，不增加系统权限；许可证与 NOTICE 随安装包保留。

所有操作按实际接口能力与当前账号/对象权限开放，不按DSM或套件精确版本禁用，也不为匹配版本要求额外系统读取权限。普通Photos/Chat账号可使用已获授权的写入；功能本身要求管理员的设置仍保留权限检查。未知结果只读恢复、不重复发送。

2026-10-14修正版测试包为`build/android-version-policy/LanStash-Android-A10-updated-debug.apk`，已通过2551项聚焦JVM、仪器源码编译、Debug构建和APK签名检查；前一包已被替代。真实NAS和设备验收仍按主计划执行。

ISO 文件菜单支持将内容挂载到已有空文件夹；文件选项里的“ISO 挂载”可查看、浏览和断开。
开机自动连接默认关闭，启用前会说明持续生效的设置。断开保留 ISO 与文件夹；结果暂时无法获取时，刷新原操作即可，不会再次提交。
实际 NAS 的挂载、自动连接和断开仍需使用专用测试资料验证。
“远程文件夹”可连接 SMB/NFS 共享，支持域账号、NFS 版本、自动连接、编辑与断开。
换位置先连接新位置，再由用户继续断开原位置；同位置修改先断开，再连接新配置。
每一步中断后可在原连接中继续查看进度，未知结果不会重复提交。密码不保存，重建表单或继续连接时重新填写；断开不删除文件。
“服务器与云盘”可管理 NAS 保存的 FTP、SFTP、WebDAV 与可用云盘连接，支持编辑、重新连接、断开和删除配置。
云盘通过系统浏览器登录，再由用户保存连接；密码与授权令牌不保存到恢复记录。
远程目录可分页浏览并下载单个文件，使用系统保存位置选择器；恢复下载前会检查原连接和原文件，连接改变时停止继续。
连接和配置分别保存，结果不明时只刷新原操作，不会自动补发。真实远程服务器与云账号兼容仍待验证。
管理员可从文件选项进入 File Station 设置，修改常规选项、分享与文件收集使用范围、远程访问名单和账号限速。
支持本机、域和 LDAP 账号，限速时间表按星期与小时编辑；未配置的用户保留群组限速含义。
不同分区分别保存，扩大访问权限会说明后果；断线后只刷新状态，不重复保存。共享页面可调整标志、背景、布局、颜色和页脚，图片可从已上传图片、NAS 文件或此设备选择，背景另有默认图片。
上传图片和保存页面分别操作，结果暂时无法取得时不会自动重试相同图片；真实设置效果仍待专用环境验证。

NAS 文件任务支持查看详情、停止进行中的任务和移除指定已结束记录。停止前说明已处理文件不会恢复，移除记录不删除文件；结果未确定时可在“未完成的操作”中刷新恢复，任务已结束不等于所有文件处理成功。

文件和文件夹可复制到另一已保存连接，详情显示两端账号、进度和各项目结果。移动先完成复制，再单独选择删除原文件，或保留原文件并结束；不会自动覆盖同名目标。
中断后可从任务中心重开原任务，刷新只读取状态；结果不明时不重复上传或删除。删除原文件前重新检查两端内容，文件夹只删除空目录。真实双 NAS、外部并发修改及系统中断仍待专用数据验证。

可从其他应用将文件或文字分享到 LanStash，选择连接和文件夹后上传。每次最多100个不同名文件，文字保存为文本文件；同名替换会明确确认。接收后可稍后处理，原应用关闭不影响已保存的副本；上传进度和失败恢复在任务页查看。移除接收草稿或清理已结束任务时，仅清理本机接收副本，不删除 NAS 文件。

照片上传/导出、跨 NAS 传输和 Office 文档准备/保存使用系统前台执行。开始后可切到其他应用，通知显示进度并可取消；系统拒绝时请回到应用重试。账号退出、权限撤销、系统超时或关闭任务会停止后续操作，并保留既有恢复记录。系统终止应用后不会自动重放照片上传、Office 覆盖或跨 NAS 删除；已保存的本机导出保留，未完成文件不可当作成功结果。

可在应用设置的“系统文件访问”中逐个开启已登录的 NAS，在 Android 文件选择器中浏览和下载。默认只读；单独允许 Office 编辑后，外部应用可以修改选中的 Word、Excel 和 PowerPoint 文件。更改先保留在本机，需回到原连接的 Office 副本中明确保存回原文件；冲突停止覆盖。编辑器异常退出时先关闭文件，再选择“接收编辑内容”，也可明确放弃本机副本。仍被编辑器使用的副本不能清理或随连接移除。删除、改名、移动与新建继续使用 LanStash 文件页。

关闭系统文件入口或退出账号后，旧入口不能继续发起读取；已经交给外部应用的文件内容无法收回。系统文件目前每次在线读取，不承诺离线目录浏览、NAS 挂载或编辑器关闭后自动上传。当前模拟器已验证系统选择器、文件描述符与编辑中断恢复；第三方编辑器及真实 NAS 的兼容仍需按 A9 条件验证。

Word、Excel、PowerPoint 文件可交给其他应用打开或编辑副本，支持 doc/docx、xls/xlsx、ppt/pptx。编辑后选择修改后的文件，再确认保存回原文件；未做修改时不上传。
原文件已变化时停止覆盖并保留编辑副本，保存结果暂时无法获取时只刷新状态。文件选项中的“编辑副本”可重新打开未结束的编辑；结束编辑只清理本机副本，移除连接前需要另存想要保留的修改。设备需有支持对应格式的文档应用。

照片页在同时获授权时提供“我的照片／共享照片”切换，单一来源直接显示。时间线、文件夹、搜索和筛选沿用选定来源；相册可以包含不同来源的照片，并按相册授予的权限打开和保存原件。
只有相册访问权时仍可浏览相册和分享列表；没有对应来源权限时不显示该来源的时间线。共享分类按账号权限和照片设置显示；Android 现有照片备份保留。

照片预览和多选工具栏可以保存原件或压缩JPEG；套件支持时，符合格式的单张照片还可以保存原尺寸JPEG。相册、文件夹和同级含文件夹的选择可保存完整ZIP。单文件选择保存位置，多选选择文件夹后逐项保存；同名文件另存，部分失败与取消会显示已保存数量，无法压缩的项目保留原格式。保存期间保持应用打开，图库月份和选择不变。

照片页的上传按钮支持多选照片/视频和导入文件夹。先选择来源、目录或允许贡献的普通相册，设置保留两份或跳过重复；文件准备完成后点击“开始上传”。目录导入可保留层级，相册接收其中的照片和视频。排队后目标固定，页面切换不会改变上传位置。

上传任务保存已完成和未结束的进度；重开应用后，在原 NAS 账号中打开上传任务查看或继续。结果暂不可用的项目只刷新状态，不自动重传。清除任务只移除本机记录和准备的副本，保留设备原件及 NAS 已接收的内容。上传中切换账号需先暂停；开始上传后可切换到其他应用，系统允许时继续处理；可从通知取消。进程结束或系统停止执行后，回到原账号查看或继续，不自动重传。

相似照片支持按月份浏览和打开完整组，组内可独立选择、查看、设置推荐、移出或拆组；移出和拆组保留所有原件，并可撤销已完成的分组更改。多组整理遇到连接中断会暂停后续，恢复状态后可继续剩余项。保存相似组时包含完整成员；“保留所选，删除其他”会进入原件删除确认。识别进度只在有待处理照片时显示。

照片可从预览进入编辑，也可长按网格或在照片操作菜单中选择多张，每次最多 100 张。支持评分、描述、拍摄日期与时间、统一向前/向后调整时间、已有标签增删及新标签创建。不同来源可批量调整评分或时间；描述与标签按同一来源编辑。仅有上传或相册浏览权限不等于拥有原件编辑权限。

“照片修改记录”显示涉及的照片和保存结果。中断后在原账号刷新状态，应用不会重新发送不确定的修改；明确部分完成可继续剩余项，时间仍按原先选定的目标保存。新标签创建成功后才应用到照片，缺少创建编号不会按同名认领。移除已完成记录只清理本机记录。

照片操作菜单可以新建空相册；选择照片后可以创建相册或加入已有相册。进入普通相册后，所有者可以改名、选择封面和删除相册，贡献者按权限移出本人提供的照片。移出照片或删除相册均保留图库原件，删除相册会同时移除该相册的分享链接。

照片操作菜单还可以创建条件相册，按照片或视频、日期、文件夹、评分、关键词、人物、主题、标签和拍摄设备自动归集照片。可先查看符合条件的数量，再保存相册；已有相册从“管理相册”进入“编辑相册规则”，改名称仍单独操作。共享照片来源只对拥有共享管理权限的账号提供。切换来源保留各自尚未保存的条件；读取不到名称的旧条件和其他已有规则会保留。条件相册不支持手工加入、移出照片或直接上传，可先上传至图库，再按规则归集。

无法继续自动收录的旧相册可从“管理相册”保存为普通相册，保留其中现有照片；旧规则可用时，也可调整条件后创建替代相册。页面会列出无法保留的旧条件，并说明旧分享将失效。新相册可用后才移除旧相册，原始照片保留；若旧相册被修改或无法移除，会保留两者并说明结果。中断后可从相册记录刷新状态，不会自动重复创建或删除。

相册所有者可从“管理相册”打开“共享设置”，停止分享、仅邀请指定成员，或允许持链接查看和下载。可添加用户或群组、调整权限、设置或清除密码及到期日期，保存后复制链接或使用系统分享。条件相册的成员仅可查看或下载；已有其他权限未修改时保持原样。只打开设置不会生成链接。修改中断后可从相册记录刷新状态；密码不会随记录保存，未发送的改密操作需要重新填写。冻结相册已有的分享可从“由我共享”进入管理。

选中照片后可从“管理相册”选择“分享所选照片”，准备完成后设置分享范围，也可取消准备。已有临时分享可从管理页停止，选择“保留为普通相册”会先保存完整相册，再移除临时分享；图库原照片保留。处理中断后可在相册操作记录中刷新，无法确认副本时会保留原分享。

照片操作菜单提供“收集照片”，也可以从文件夹或普通相册中快捷创建。可选择保存位置、关联可上传的相册、填写说明并限制文件大小和到期日期，也可在表单内新建普通相册。共享来源没有管理权限时，需要选择有上传权限的现有文件夹。“共享”中的照片收集列表支持按标题搜索、编辑、删除及复制链接；删除收集链接不删除已收集照片。中断后从“照片收集操作记录”刷新结果，不会自动重建链接，尚未发送的表单需要重新填写。

照片文件夹支持新建子目录、重命名、保存照片排序，以及从本目录或子目录选择封面。排序可按名称、大小、类型或拍摄时间升降序显示；可查看但无管理权限的目录仍可排序。路径按钮可返回上级位置。中断后可从“文件夹操作记录”刷新结果，未发送的记录重新打开表单，已发送的操作不会自动重做。

照片和文件夹可一起选择后移动或复制到同一 NAS 中有权限的位置，最多选择100项；目录菜单和照片预览也提供快捷入口。同名文件可跳过或明确确认替换，共享照片可复制到我的照片，移动则保留在共享来源。混选文件夹和照片时可删除全部所选内容，确认页说明子目录及相册引用的影响。文件操作记录保留中断前的任务，打开照片库时自动更新进度；丢失操作结果时不自动重做，也不猜测哪些项目已完成。

照片菜单的“后台任务”显示当前账号在 NAS 上的复制与移动进度，可按进行中或已结束筛选、查看失败原因并打开有权访问的目标文件夹。停止任务会保留已经处理的内容；清理只移除所选的已结束记录，确认后新完成的任务保留。关闭页面只停止刷新。停止或清理的结果暂时不可用时，可从页面内的“操作记录”刷新，应用不会重复发送；原复制或移动的结果尚未取回时不能提前清理其记录。

预览照片或选择多张照片后，可确认删除个人或共享原件；确认页列出完整选择，并说明相册引用也会移除、恢复取决于 NAS 设置。批量逐项执行，遇到中断或失败便停止剩余项目。删除记录在重新打开应用后保留，已发送项目自动更新进度；剩余项目可重新确认继续或取消。成功后留在原月份或目录，只有实际完成的照片移除；共享来源必须具备管理权限。

共享图库的完整访问用户可从前两层文件夹的菜单设置访问范围、成员权限和密码，并复制现有链接。第一层可选择把权限应用到全部子文件夹，保存前说明覆盖后果；第二层受上级限制时保留查看。修改记录可在重启后刷新，结果不明时不会重复保存，权限已保存但默认选项未保存会分别说明。

照片菜单提供“照片显示”“重复文件处理”和“个人识别设置”。日/月分组、日期与时钟格式、默认照片排序和预览信息可保存到当前账号；显示变化保留当前月份与选择，已单独排序的文件夹仍按原顺序显示。重复处理规则用于之后的新上传、移动和复制，选择默认替换会说明覆盖后果。个人识别仅调整管理员已开启且当前账号可用的选项，关闭人物或主题后对应个人分类同步隐藏，共享分类保持原状。保存中断可从“设置保存记录”刷新，已发送的操作不会再次提交。

管理员可从照片菜单打开“共享图库设置”，启用或停用共享图库，调整人物、主题、相似照片识别和顶层文件夹公开分享。停用保留照片；个人图库不可用时不能停用最后一个图库。只显示可读取的选项，全局关闭的识别保留只读提示。保存前重新检查权限和当前设置，启停与公开分享变化说明具体后果；中断后可从设置保存记录刷新，已发送的操作不会重复保存。个人浏览位置和选择保留，共享图库关闭后会退出该来源。

管理员也可从“全局设置”调整识别、用户分享、访客照片详情、排除格式和原尺寸 JPEG 下载。全局关闭识别会关闭当前个人图库与共享图库的对应选项，重新开启不会自动恢复图库开关。转换缓存可单独查看、刷新与清理，原始照片保留；关闭原尺寸 JPEG 时先清理转换副本。修改前会说明影响范围，部分保存会显示实际结果，重新打开可保存剩余更改；中断后只读取进度，不重复发送。缓存读取错误不影响其他设置，离开页面停止刷新。

“共享成员”支持搜索、添加或移除用户和群组，调整完整管理、自定义文件夹权限及照片备份。文件夹权限可展开两层，逐项修改或批量授予、撤销；公开访问仍保留其原有权限下限。新增或降级为自定义权限时先编辑文件夹，取消不会改变 NAS，最后保存会说明影响。中断后从“成员修改记录”继续读取结果，已发送的修改不会重复提交；部分保存可重新打开当前名单再修改。本人共享权限变化后会清除旧照片并重新加载原浏览位置，个人图库的浏览位置保持。

“图库维护”可对当前来源重建照片索引或预览，显示剩余项目；共享来源仅限 NAS 管理员。启动前会说明目标与浏览速度影响，已在处理时不能重复启动。网络中断后保留操作记录，只刷新状态，不重复发送；未收到回复时不会误报完成。维护不会改变当前月份或已选照片。

“新格式预览”可处理照片套件的新媒体格式提示：选择生成预览或稍后。管理员生成会涉及所有用户，普通账号仅涉及“我的照片”，生成前会明确说明。生成请求已收到而提示未保存时，可以继续保存提示；断网或重启后不会重复启动生成。当前月份与选择保持不变。

主题分类支持“显示或隐藏主题”，可搜索已隐藏的主题后恢复显示；照片数量不足的主题会说明原因。在主题内选择照片或打开大图，可将单张照片设为封面，或把选中的照片移出错误分类。移出保留原照片，并在剩余照片过少时说明主题可能隐藏。完成后保留当前月份和其他照片；中断或重开后刷新只读取结果，不重复操作。共享主题需要相应管理权限。

照片菜单中的“自动生成预览”可开启“补全缺少的预览”，使用当前设备在照片页面打开时处理支持的照片与视频，原件保持不变。处理时可暂停或继续；离开照片页面会停止领取新项目。较大视频可能耗时较长并增加耗电，设备无法处理时可以稍后重试或换设备。上传中断后只读取已有结果，不重复上传；完成后保留当前月份与选择，只刷新对应预览。

可在图库选择照片或打开大图后“更新预览”，照片与视频原件保持不变。照片菜单中的“预览更新”可查看未完成项目并选择继续，每次最多100项；操作记录逐项显示结果。中断或重启后刷新只查询已有结果，不重复执行。更新完成后保留当前月份与选择，只刷新相关预览。


照片预览提供“向左旋转并保存”，可将支持的照片逆时针旋转90度并保存到 NAS。保存时保留当前位置与选择，不能重复点击或同时下载；失败恢复原显示。若结果暂时不可用，可刷新读取，重启后也不会再次旋转。视频、全景、GIF 和 WebP 不提供此操作，相册照片仍需具备原件编辑权限。

照片菜单或预览中的“幻灯片”可连续查看当前范围，支持上一张、暂停/继续、下一张和停止。图片显示3秒，视频播完再切换；键盘可用空格和左右键，返回键关闭。读取或播放失败会暂停，可重试或切换照片。播放不改变图库当前位置与选择，切到后台会停止。

相册内可按名称、大小、类型或拍摄时间排序；相册首页可选择“全部相册／我的相册”并调整列表顺序。“与我共享”和“与他人共享”各自保存排序，照片收集列表保持原有方式。选择保存在 NAS，翻页和重新打开时沿用；排序保存后保留当前相册和照片选择。读取偏好失败仍可浏览并重试，网页上的并发修改不会被旧表单覆盖。

“相册操作记录”保留保存结果，中断后在原账号中刷新状态，不会重复创建或提交。结果不明的相册或照片会暂停相关修改，明确部分完成时可以继续剩余照片。创建未返回编号时，不会把另一个同名相册当作本次结果；移除完成记录只清理本机记录。

## 下载任务

下载页支持完整任务列表、单项详情和长按多选；可暂停、继续、移除任务及修改保存目录。结束并移出未完成文件会先说明文件可能不可用，只报告任务结果，实际文件以目标目录为准。

链接、RSS/BT 搜索结果和任务文件使用同一创建表单。选择任务文件后可设置当次解压密码与保存目录，点击“创建任务”才发送；默认目录可留空。创建被接受后无需等待任务编号，结果未知时保留记录并阻止同一来源重复提交。

“下载操作记录”保留批次和设置进度，重新打开应用后只读取结果，明确结束前不自动重发；部分完成可继续或取消剩余项目。设置只显示NAS返回的可用字段，管理员可保存修改，普通账号保持只读。RSS只管理已有订阅的读取与更新；BT搜索保留来源、分类和排序。

## 代码边界

```text
app/src/main/.../domain/    领域模型、状态和统一错误语义
app/src/main/.../network/   DSM Web API 传输、登录与解析
app/src/main/.../storage/   Keystore 保护的会话与本机偏好
app/src/main/.../data/      DsmRepository 门面与按领域拆分的 Repository
app/src/main/.../ui/        Compose 平台原生界面
```

`DsmRepository` 与 `AppViewModel` 是既有 Compose 兼容门面。结构拆分须同步受影响的调用方，
保持现有用户入口、DSM 请求契约、`MutationResult` 映射、持久化键、状态顺序、WorkManager 唯一任务名以及
取消、重试和退出语义。

## 真实环境边界

真实设备、证书、WorkManager、后台限制、系统选择器、跨 NAS、真实 DSM/套件返回和
危险写副作用均为 `PENDING_USER_VALIDATION`。缺少这些环境不阻塞独立源码和自动化工作，
但未验证的高风险入口必须继续关闭、只读或受能力门保护。

人物卡片菜单支持修改名称、把其他人物合并到当前人物，以及显示或隐藏人物。人物页菜单可以搜索包含隐藏项的完整列表，再选择同一显示目标保存；一次最多选择100个人物。合并保留照片，但所选分组将不再单独显示；清空少于两张照片的小分组名称前会说明隐藏后果。保存中断后可从“最近修改”刷新状态，已发送操作不重复执行。人物封面按实际返回的类型加载，操作结果保持当前照片月份和选择。刷新读取失败后重试会保留尚未保存的名称。当前还支持在人物详情选择照片后逐脸移出、归入已有或新人物，以及单张设为人物封面。移出人脸保留原件；同一照片中仍有该人物的人脸时，照片继续留在本人物内。未完成修改仍可从“最近修改”刷新状态；新人物和封面只有结果明确时才完成。177项聚焦JVM通过；同一应用APK手机中文浅色/深色二倍字号和平板英文浅色各8项通过，平板英文深色二倍字号首轮7/8，测试收起键盘修正后定点1/1通过。真实NAS与物理设备仍待按主计划验收。
