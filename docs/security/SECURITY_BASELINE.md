# 安全与隐私基线

协作与授权遵循 [AGENTS.md](../../AGENTS.md)，漏洞披露遵循 [SECURITY.md](../../SECURITY.md)。本页只定义产品安全边界；功能状态见[平台矩阵](../progress/PLATFORM_MATRIX.md)。

## 连接与凭据

- DSM 只使用 HTTPS。密码与 OTP 不明文持久化；会话秘密使用平台安全存储，不进入 URL、日志、崩溃报告、分析平台或普通任务摘要。
- 自签名证书按主机绑定并确认 SHA-256 指纹；已信任证书变化时阻止静默连接。
- QuickConnect 中继只接受官方中继域名，先核对目标身份再提交凭据；强制系统证书信任，不允许用户确认绕过异常中继证书。
- NAS 配置、账号与操作目标严格隔离；退出 NAS 登录、权限失效和配置删除按既定策略清理会话。安全存储和预览缓存不得进入系统云备份。

## 数据与证据

文件名、路径、缩略图、预览、正文及消息都属于隐私。禁止提交密码、OTP、SID、SynoToken、Cookie、DID、证书私钥、签名材料、真实主机/账号/路径/用户数据，以及未脱敏 HAR、PCAP、DSM 响应和日志。临时调试材料在任务结束前清理。

[社区报告](../compatibility/COMMUNITY_COMPATIBILITY_GUIDE_ZH.md)只接受 Schema 固定字段和结果枚举。公开产品型号可以记录，设备名、序列号、MAC 等唯一标识不可记录；不接收日志、截图、原始响应或附件。发现疑似秘密不得复制到评论、提交或外部系统，应移除并重新提交安全版本。社区自报不能升级维护者 API 证据或自动开启写能力。

## 写操作、删除与恢复

- 提交前检查实际能力、账号/对象权限及目标快照，危险操作显示明确目标和后果并确认；保留重复提交保护与最终结果校验。
- 是否可恢复以实际回收站状态为准；回收站内删除按永久删除加强确认，恢复冲突默认不覆盖。
- 请求被接受不等于完成；超时或结果不明时查询原目标，不自动重放、不认领外部变化。
- 未验证可能造成数据丢失、凭据泄露、越权或不可逆副作用的入口保持关闭、只读或受能力开关保护；不影响独立功能推进。证据规则见 [API 发现流程](../api/discovery/README.md)。

## 发布

Release 不含抓包 CA、代理配置、调试网络日志、测试账号、临时响应或本地配置。正式 App 与扩展保持规定签名和 Hardened Runtime 权限；临时测试例外不得进入正式包。签名、公证、升级和系统扩展实际加载须按[发布手册](../releases/MACOS_GITHUB_RELEASE_ZH.md)及目标平台验证，不能以单元测试代替。
