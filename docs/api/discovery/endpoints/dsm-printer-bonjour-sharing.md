## 证据边界

当前唯一证据来自仓库既有的 DSM 前端静态目录整理，只确认
`SYNO.Core.ExternalDevice.Printer.BonjourSharing` 存在候选 `get` 方法。没有在当前
DSM 环境中观察到请求，也没有取得脱敏响应。因此版本、路径、请求格式、参数、响应
容器、字段、权限和错误语义全部未验证，客户端不发起该请求。

通用文件服务中的 Bonjour/Avahi 设置来自其他 API，不能等同、复用或推断为打印机
Bonjour 共享状态。

## 响应与错误

成功容器和字段均未知。当前不能判断该端点表达以下哪一种语义：

- Bonjour 广播开关；
- 打印机共享功能是否可用；
- 是否至少存在一台已共享打印机；
- 包含打印机或队列清单的复合响应。

`false`、`null`、空对象、字段缺失、接口缺失、硬件不支持、未连接打印机、共享关闭和
无权限不能互相替代。任何未知字符串也不得通过宽松布尔转换误报为“已关闭”。

## 能力探测与降级

- 启用条件：当前无；未来必须先确认服务端版本范围和客户端明确支持版本相交；
- 新版本默认行为：关闭，不选择服务端最高版本，不猜测参数或字段；
- 接口缺失、版本未知、权限不足或结构未知：单项不可用且零猜测请求；
- 字段缺失或类型变化：不得把未知值转换成 `false`；
- 替代的官方 API：当前未发现；
- 功能开关：没有客户端功能开关，能力整体关闭。

## 安全与副作用

- 会读取的数据类别：未知；可能包含打印机或队列信息，因此先按中风险处理；

- 临时数据清理：本批没有浏览器导出、响应、截图或调试文件。
