## 请求与语义

- POST /webapi/entry.cgi，api=SYNO.Foto.BackgroundTask.File、method=delete、version=1。
- 业务参数采用 JSON 编码：item_id=[照片项目 ID]，folder_id=[]；不接受路径，不使用 File Station 删除。
- 这是原件删除，不是 NormalAlbum.delete_item 的“从相册移除”。恢复能力由 NAS 配置决定，不能保证可恢复。
- 未知响应、错误、取消、任务尚未完成均不能视为确认成功。静态任务回执仅证明可能提交，不证明目标已消失。
- 本次实际回执为 data.task_info，初始 status="waiting"、completion=0、total=1。随后 SYNO.Foto.BackgroundTask.Info.get_status v1、id=[任务标识] 返回 data.list 中 status="done"、completion=1、total=1、error=0、skip=0。

## 2026-09-30 文件夹与照片混合删除

端点沿photos-item-deletion（internal/critical）。只读官方react_bundle.js主动作绑定确认：个人/共享HandleDelete→DeleteItemAndFolder→BackgroundTask.File.delete v1，POST /webapi/entry.cgi，参数item_id整数数组、folder_id整数数组；支持当前文件夹中同时选择多个子目录与照片。返回data.task_info.id，官方等待相同编号BACKGROUND_TASK_DONE通知再从界面移除项目/目录。此前发现的Browse.Folder.delete helper并非主界面此流程，不能用它替代。当前静态核对没有真实写请求，也未增加环境兼容verifications。

确认窗列出固定照片/文件夹快照及数量，明确整个目录内全部内容和相册引用都会受影响、恢复取决于NAS设置。个人/共享按来源调用Foto/FotoTeam.BackgroundTask.File，任务状态统一Foto.BackgroundTask.Info.get_status v1(id数组)。macOS既有组合根deletionEnabled=true继续开放；共享库默认删除策略仍保留，未引入人工“未实测”门禁。需要BackgroundTask.File v1、Info v1、Folder v2与Item v5的JSON能力。

删除前：目录必须非根目录、有原始完整路径/父编号、同一空间/父目录、不重复；重新读取父目录view、每个目标目录路径/id/parent及manage（共享管理者例外沿既有语义）。混选照片须在该父目录内且无相册上下文，逐项重新核对完整照片身份及目录管理权。沿已有全局写锁、操作编号绑定/去重、权限代次和取消检查；存在未知删除或管理任务时不提交新写入。没有通过名称猜测目标、没有扫描目录后逐张替代原生目录删除。

自动结果核对采用同一任务编号get_status：只有done且error/skip/overwrite为0才继续；重新读取原父目录身份及view，按100条完整分页枚举子目录，重复页/父编号错误拒绝，所有目标id不再列出；混选照片分别Item.get v5成功空列表。任务成功加目录/照片回读共同构成原生完成判断，不声称已直接验证文件系统每个后代。并发移动、索引时效仍待用户实际环境验收。正常完成只更新当前目录卡片与已确认照片、选择和分页offset；核对期间进入被删目录则回到存活父目录，不跳时间线。其他空间或同编号相册不被当成目录移除。

未知回执无法取得可靠任务编号，保持待核对且不重发；不通过猜测错误码或父目录缺项推断成功。任务报告失败/跳过时返回部分失败，因无逐目录结果，不根据目录不可见推断哪些目标已删除，不误移除这些卡片；用户可刷新核实，不能保证整个目录原子删除。父目录无权、响应错误、任务未完成、成功但目标仍列出等继续只读核对。与现有单照片删除一样，待核对记录限当前会话，本轮未改持久化。

## 2026-10-01 macOS 长断线后的持续自动核对

不改变任何删除请求或公开契约。单张/批量照片在初始六轮后由图库生命周期继续每15秒只读核对；不要求用户手动点击。后台核对不锁住普通浏览，不重新发出delete。离开、取消或禁用模块后停止应用晚到结果；重新进入仍按原profile/space/unit目标继续核对。同一时刻至多一个结果读取，权限检查仍由Repository执行。已确认删除影响当前分页窗口时，使使用旧偏移的在途分页失效，保留月份与已加载内容，下次按修正位置继续。

目录和照片混合删除同样纳入已有持续管理任务核对，复用operationID，不重发删除命令；局部更新及已删除目录返回父目录语义不变。macOS移除手动核对按钮并使用自动继续文案；移动端界面与既有手动入口不变。无持久化变化，应用退出后的未决任务恢复不在本轮实现范围。

PENDING_USER_VALIDATION：在专用可丢弃照片上确认删除，断网超过首轮约20秒再恢复，预期无需点击、自动原地移除并保留历史月份；重复点击不二次删除。核对等待时向下分页、切换月份、离开重进，旧响应不得复现已删除照片或覆盖修正后的偏移。共享权限撤回时不越权、不伪造完成；混选目录等待后自动回读并保留父目录。需回传脱敏版本、空间、步骤、提示与预期/实际差异，勿提供真实照片/路径/凭据。此轮没有NAS真实删除，不提高接口证据等级。
