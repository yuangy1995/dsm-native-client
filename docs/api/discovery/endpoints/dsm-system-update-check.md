# DSM 系统更新检查内部 API

## 标识

| 字段 | 值 |
| --- | --- |
| 端点或端点组标识 | `dsm-system-update-check` |
| 项目组件标识 | `dsm-core` |
| 所属范围 | DSM 系统更新 |
| 能力名称 | 当前版本与可用更新只读检查 |
| 分类 | `internal` |
| 操作性质 | `read` |
| 风险等级 | `medium` |

## 请求契约

检查由两个只读请求组成：

| API / 方法 | 版本 | 参数 | 用途 |
| --- | ---: | --- | --- |
| `SYNO.Core.System.info` | 能力发现范围内版本 | 无业务参数 | 读取当前 DSM 版本 |
| `SYNO.Core.Upgrade.Server.check` | v3 | `user_reading=true`、`need_auto_smallupdate=true`、`need_promotion=false` | 读取当前账号可见的更新候选 |

路径和请求格式必须由 `SYNO.API.Info` 运行时发现。任一能力缺失、v3 不在服务器声明范围
或检查失败时，客户端只显示检查失败，不尝试其他版本、下载或安装方法。

## 响应解释

- 当前版本优先读取 `System.info` 的 `firmware_ver`，兼容 `version`。
- 更新版本读取 `Upgrade.Server.check` 的 `update.version`。
- 更新说明只在候选更新中读取 `release_note`、`release_notes`、`whats_new` 或
  `description` 的第一个非空值。
- 版本和说明只清理首尾空白，服务器返回的用户可见正文保持原文。
- 候选版本为空，或与当前版本完全相同时，不宣告存在更新。
- 客户端不根据版本字符串自行计算升级路径，也不把 `promotion` 当作系统更新。

macOS 检查结果会明确说明安装仍需在 DSM 中安排；按钮和图标只表达“检查”，不暗示已经
下载。发布说明存在时随候选版本显示，不包含安装按钮。

## 安装边界

当前证据只覆盖 `check`。静态目录没有形成系统更新下载、上传、校验、安装、取消、任务
轮询或重启恢复的稳定契约，因此客户端保持这些写入口关闭。

增加安装能力前至少需要版本化记录：

1. 更新来源、签名/校验、目标 build 与适用机型的权威字段；
2. 下载、准备、安装、迁移、重启和失败回滚的状态机与任务标识；
3. 空间、套件、存储池、加密卷、UPS、电源和管理员权限预检；
4. 提交前取消、提交后取消、断线、超时与不可回读阶段的结果语义；
5. 全局防重复、用户确认、维护窗口提示、最终 build 回读和服务恢复核对。

任何安装提交都可能中断服务并重启 NAS；未满足这些条件时不得根据接口名称或 DSM 网页
按钮猜测请求。

## 能力探测与降级

- `System` 与 `Upgrade.Server` 必须分别存在，v3 必须落在更新服务的发现范围内。
- 更新检查失败只影响本次检查，不阻断系统概况、文件或其他设置页面。
- 不自动重试检查，不把网络错误解释为“已是最新版本”。
- 当前版本缺失时仍可展示服务器明确返回的候选版本，但不自行比较版本号。
- 新 DSM build 上继续允许只读检查；安装写入仍默认关闭。

## 客户端与测试

- Apple 领域：`NasSystemUpdateInfo`。
- Apple Adapter：`DsmNasAdministrationRepository.checkSystemUpdate()`。
- macOS：总览页提供检查按钮、忙碌禁用、可用更新/无更新/失败反馈和可选发布说明。
- Android：总览页使用相同双请求契约，提供忙碌禁用、可用更新/无更新/失败重试、可选发布说明和 TalkBack 状态通知；能力不足时零请求降级。
- Windows：NAS 详情页提供独立“系统更新”分区，复用系统概览当前版本并固定执行 v3 `check`；仅展示当前版本、候选版本和普通文字发布说明，失败不阻断其他分区。
- iPhone、iPad、Android 与 Windows：安装链路均未迁移。
- 请求不包含账号、地址、Cookie、SID、SynoToken 或真实响应 Fixture。

## 未验证事项

- 无更新、分阶段更新、重大版本、回退版本、区域限制、代理离线和更新服务维护时的所有
  真实响应形态尚未覆盖。
- 发布说明可能包含富文本；当前仅按普通文字展示。
- 下载、安装、取消、任务进度、重启与恢复均未验证且保持关闭。
