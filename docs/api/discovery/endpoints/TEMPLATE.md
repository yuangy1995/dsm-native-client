# 内部接口定义模板

在已有功能域文件中补充或建立必要端点组；一个事实只在一个正文维护，不追加波次/平台施工日志。每个端点在所属功能域文件中以 `<a id="endpoint_id"></a>` 锚点标记，并在[端点索引](INDEX.md)登记；机器 `documentRef` 只指向文件，不带锚点。

## 标识与来源

- endpoint_id、组件、official/internal、read/write/mixed、风险。
- 官方指南URL或[环境证据条目](../environments/INDEX.md)；未知字段明确未知。

## 请求与响应

| API / method / 固定版本 | 路径与编码 | 必需/可选参数及单位 | 关键响应、错误与权限 |
| --- | --- | --- | --- |
| 待填写 | 只写相对路径，不含秘密 | 稳定类型/枚举，不用界面文案 | 区分缺失、空值、失败与未知 |

只记录当前定义和必要版本差异。通用认证、错误、危险写与不确定结果引用[通用标准](../../reference/common.md)，不复制另一套规则。

## 本功能的安全与结果

固定目标身份、权限条件、真实副作用、确认、去重、写后证据与无法确认的边界；缺能力/权限/字段时局部降级，不猜请求或把失败当空数据。没有实测不能宣称已验证，也不追加精确版本白名单。

## 定位

链接现行适配器、必要Schema/fixture/正式测试。版本证据只维护于环境索引与机器verification，功能做了多少只维护于[平台矩阵](../../../progress/PLATFORM_MATRIX.md)，缺口及用户验证只维护于[已知限制](../../../progress/KNOWN_LIMITATIONS.md)。
