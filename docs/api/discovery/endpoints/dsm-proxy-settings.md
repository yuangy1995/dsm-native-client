# DSM 互联网代理设置内部 API

## 标识

| 字段 | 值 |
| --- | --- |
| 端点或端点组标识 | `dsm-proxy-settings` |
| 项目组件标识 | `dsm-core` |
| 所属范围 | DSM 控制面板网络代理 |
| 能力名称 | HTTP 代理开关、地址与端口 |
| 分类 | `internal` |
| 操作性质 | `read / write` |
| 风险等级 | `high` |

## 请求契约

| 字段 | 值 |
| --- | --- |
| API 名称 | `SYNO.Core.Network.Proxy` |
| 路径 | 运行时通过 `SYNO.API.Info` 发现 |
| HTTP 方法 | `POST` |
| API 版本 | v1 |
| 鉴权机制 | DSM 会话 Cookie/表单与令牌请求头/表单，不记录值 |
| 内容类型 | `application/x-www-form-urlencoded` |

| 方法 | 参数 | 类型 | 必需 | 含义 | 合成示例 |
| --- | --- | --- | --- | --- | --- |
| `get` | 无 | - | - | 读取代理开关、地址与端口 | - |
| `set` | `enable` | `boolean` | 是 | 启用或停用互联网代理 | `true` |
| `set` | `http_host` | `string` | 启用时 | 不含协议和路径的代理主机 | `proxy.example.invalid` |
| `set` | `http_port` | `integer` | 启用时 | 代理端口 | `3128` |

启用代理时，客户端先去除地址两端空白，拒绝协议、路径、查询、用户信息和内部空白，
并验证端口位于 1 到 65535。客户端不读取、保存或提交代理密码。

## 响应、错误与恢复

读取响应必须包含 `enable`；启用代理时，保存结果按开关、地址和端口三个实际变化字段
分别回读计数。停用代理时只校验开关，不把 DSM 保留的旧地址和端口误判为失败。

| 场景 | 结果语义 | 恢复方式 |
| --- | --- | --- |
| 地址或端口无效 | 提交前确认失败 | 修正地址与端口 |
| API 未发现 | 不支持 | 不发送读取或写请求 |
| 权限不足 | 权限拒绝 | 使用具备网络管理权限的账号 |
| 提交后所有变化字段匹配 | 确认成功 | 使用回读值更新界面 |
| 只有部分变化字段匹配 | 部分成功 | 重新读取开关、地址和端口后逐项核对 |
| 提交断网、超时或响应无效 | 结果未知 | 不自动重放，先重新读取 |
| 回读失败或提交后取消 | 已提交结果未确认 | 恢复连接后重新读取 |
| 同时再次保存 | 重复提交冲突 | 等待当前保存结束 |

## 能力探测与降级

- 未发现 `SYNO.Core.Network.Proxy` 时不读取或提交设置。
- 缺少 `enable` 时视为无效响应，不显示可能错误的状态。
- macOS 按用户明确授权提供测试入口，以实际接口版本、权限、输入、确认、防重复和结果核查判断可用性，不仅因未实测固定关闭。新 DSM build 的真实行为仍待验证；其他平台以其最新授权和实施状态为准。
- 提交前失败可以在修正条件后重试；提交开始后的异常必须先回读。
- 代理设置失败不阻断文件、照片、消息或其他 NAS 设置。
- 当前项目未找到覆盖该控制面板设置的统一公开写 API。

## 安全与副作用

- 启用或修改代理可能中断 NAS 的更新、套件、通知及其他外网访问。
- Repository 与 macOS 模型共同阻止并发保存。
- 请求 Fixture 只使用 `.example.invalid` 合成地址，不记录真实代理、账号、密码、NAS
  地址、会话或完整 DSM 响应。
- 当前批次不安装代理 CA，不改变证书信任、防火墙、DNS 或默认网关。

## 未验证事项

- 不同 DSM build、权限、认证代理和直连/QuickConnect 组合下的真实写入副作用尚未验证。
- DSM 对无效域名、IPv6、认证代理和不可达代理的具体错误码尚未收集。
- 各端源码与合成结果不能证明真实设置写入；当前状态与专用目标验收见平台矩阵及已知限制。
- Windows 实机读取为 `PENDING_USER_VALIDATION`：在已记录版本、具备对应读取权限的
  测试环境核对开关和可用端口；读取失败应提示恢复，不应变为关闭。仅回传版本类别、
  操作和脱敏错误分类，不回传地址、账号或原始响应。写入口继续关闭，不做真实写探测。

## 证据与实现范围

接口证据按[环境记录](../environments/INDEX.md)中的日期、版本、权限和场景读取；静态线索与合成测试不能提升真实行为等级。各端实现及当前缺口只维护于[平台矩阵](../../../progress/PLATFORM_MATRIX.md)和[已知限制](../../../progress/KNOWN_LIMITATIONS.md)。通用认证、危险写与结果规则见[通用标准](../../reference/common.md)。
