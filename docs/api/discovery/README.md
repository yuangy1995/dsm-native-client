# 私有 API 发现与证据

[当前接口](endpoints/INDEX.md)只维护请求、响应、权限和结果语义；[环境索引](environments/INDEX.md)保留每次观察的日期、版本、来源和证据边界；[机器索引](../../../contracts/private-api/compatibility.json)连接稳定端点与证据。功能做了多少见[平台矩阵](../../progress/PLATFORM_MATRIX.md)，未验或未完成项见[已知限制](../../progress/KNOWN_LIMITATIONS.md)。

## 发现规则

1. 优先公开 API。内部接口必须明确标记；发现默认只读，只观察官方页面必要请求，不为探测创建、修改、删除、控制任务或改变网络/权限。
2. 开始前按[环境模板](environments/TEMPLATE.md)建立临时草稿或索引条目，记录 DSM 版本/build/Update、完整套件版本、日期、连接与权限类别、来源。完成后将必要字段和结论合入环境索引的独立日期条目，删除临时文件。
3. 写验证需明确授权的专用目标、权限检查、具体风险确认、重复提交保护与结果复查；授权与结论只适用于实际场景。
4. 不保存原始 HAR、凭据、真实地址/账号/路径/内容/日志或响应。正式 fixture 必须彻底重建或脱敏，并区分 synthetic 与 real-redacted。临时响应、截图和脚本收尾删除。
5. 页面文案、混淆变量名和偶然请求顺序不是稳定契约；未知方法/参数不猜测，静态 API 名称不足以发请求。

## 证据等级

| 等级 | 能证明什么 |
| --- | --- |
| static | 官方资源中的候选名称或结构；不证明当前请求成功 |
| observed | 已记录环境中实际出现的请求形态；不证明结果或副作用 |
| read-verified | 成功只读响应及字段已核对，仅适用该版本/权限/场景 |
| behavior-verified | 指定受控写入及最终状态已复查，仅覆盖实际操作 |
| failed | 已复现失败；须保留条件、错误语义与降级 |

页面存在、能力发现、合成测试、客户端构建、官方网页操作和原生端实机验收分别记载。测试数量不是兼容结论；未验证不能填成通过。

## 设备与升级

使用 lab-a、lab-b 等稳定匿名别名；同版本不能证明同设备，无法归属的观察保留“待归属”，不加入已有设备 verification。每个设备最多一个 current 基线；同机升级保留旧记录为 historical，新记录通过 supersedes 关联。保留原日期、版本、权限与失败，不以当前说明覆盖历史事实。

升级按[环境条目的升级差异](environments/TEMPLATE.md#升级差异)比较 API/path/版本、必需参数、字段类型、错误与权限，更新同一端点定义、索引、受影响 fixture/测试及平台影响。没有版本级行为证据不能宣称兼容已验证；实际入口依据能力、参数、权限与安全结果规则，不能增加精确版本白名单。涉及数据丢失、越权等尚未验证的风险，遵循 AGENTS 的相关入口保护要求。

## 维护边界

一个端点或紧密关联组只有一个稳定定义，保留 endpoint_id；格式见[端点模板](endpoints/TEMPLATE.md)。机器 documentRef 指向该定义，evidenceRefs 指向来源。参数或公开契约变更另行评估五端影响并取得必要授权；文档结构调整不授权协议、Schema 或运行行为变更。
