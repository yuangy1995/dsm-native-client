## 证据来源

- 既有 vmm-internal 记录、官方页面自然读取请求和已加载静态资源。
- macOS updateVirtualMachine 与正式测试仅作定位线索，不作真实环境证据。

## 发现范围

- 目标：说明、autorun、cpu_weight 的读取字段类型与最终核查条件。
- 不执行创建、保存、删除、开关机、克隆、迁移、导入或权限修改。
- 不猜测内部字段，不将公开 autorun 值外推为内部接口行为。

## 安全检查

- 仅保留版本和结构白名单，不保存主机、账号、VM 名称、路径、响应正文、截图或会话值。
- 观察完成后关闭临时监听并清除内存中的响应；无原始 HAR 导出。

## 结论

- 浏览器选择目标后连续两次返回 Debugger unattached；未能观察官方请求或静态资源，
  因此没有新 read-verified/static 浏览器证据，也没有更新设备/套件版本。
- 没有建立网络监听、下载响应或保存截图，无需清理浏览器内存抓包。
- 源码复核证明旧 updateVirtualMachine 未核查 desc/cpu_weight/autorun。本轮仅对
  已有字段与实际发送值增加精确相等核查，读取继续使用既有内部 Guest.list；不解释
  内部 autorun 0/1 的业务意义、不新增接口或参数、不升级真实环境验证等级。
- 当前写方法仍缺专用环境行为验证；Swift 本机不可用，新增回归为待执行。
