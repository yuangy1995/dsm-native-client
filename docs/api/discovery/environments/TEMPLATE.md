# 环境证据条目模板

开始发现前可复制本模板作临时草稿；完成后合入[INDEX](INDEX.md)的新日期/用途锚点并删除草稿，不保留独立施工日志。未知字段明确未知，不用历史同版本补填。

## YYYY-MM-DD-topic

| 必备字段 | 记录值 |
| --- | --- |
| 日期与来源 | 官方指南URL / 官方页面请求 / 静态资源路径 / 客户端验证；按事实区分 |
| 环境与设备 | 稳定环境ID、lab-a等别名；关系未知则待归属 |
| 基线关系 | current/historical、supersedes；未知升级关系不猜 |
| DSM与套件 | DSM版本/build/Update；相关完整套件版本及核实来源 |
| 条件 | 连接、证书、权限、必要架构类别；不含地址/账号 |
| 方法级结果 | API/method/version、场景、关键字段/错误、证据等级 |
| 限制 | 未验证的方法/权限/非空响应/设备条件；官方网页与原生端分别说明 |

仅保留理解兼容所需的最小结论；请求字段定义放稳定端点，平台进度放平台矩阵，用户验收放已知限制。不得保存秘密、真实用户内容或原始响应。

### 升级差异

在新条目附旧/新环境ID及supersedes，列API/path/版本/必需参数/字段类型/错误/权限差异、影响端点和处置。旧观察保留原日期与结果，新条目不覆盖历史。没有行为验证不能宣称兼容通过；入口遵循实际能力、权限及安全规则，不按精确版本设白名单。
