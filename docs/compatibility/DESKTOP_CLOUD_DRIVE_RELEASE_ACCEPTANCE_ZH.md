# macOS 云盘正式签名验收

本清单只验证 macOS File Provider；Windows Cloud Files 与移动 Files 的范围见[平台矩阵](../progress/PLATFORM_MATRIX.md)。签名、打包、公证、升级源和回滚流程统一见[发布手册](../releases/MACOS_GITHUB_RELEASE_ZH.md)，实现与恢复约束见[平台集成](../development/PLATFORM_INTEGRATION.md)。

自动化、合成基准及临时签名不能代替正式包、Finder 和真实 NAS。以下是用例定义，不是执行结果；缺少条件时记录 `PENDING_USER_VALIDATION`、未执行原因与影响范围，不把其他设备或版本的通过结果移植过来。

## 前置条件与覆盖

使用专用 Mac、账号、可丢弃 NAS 数据和可恢复测试快照，保留管理员恢复路径。正式 App/扩展须同团队、正确 entitlement/App Group/共享钥匙串，完成公证、票据装订、Gatekeeper 和实际扩展加载检查。临时签名包没有扩展，不能用于本清单。只读用例在关闭编辑/删除的映射中执行；写回另依当前功能范围授权，不能由本表的读取结果代替。

| 维度 | 覆盖组合 |
| --- | --- |
| 安装与系统 | 上一公开版本原位升级、全新安装；macOS 14、15、当前支持稳定大版本；Apple Silicon/Intel |
| 连接与证书 | 局域网、QuickConnect 直连/中继；公共 CA、自签名/私有 CA |
| 缓存卷 | 系统盘、其他内置 APFS 卷、macOS 15+ 合格外接 APFS SSD、不合格可移动卷 |
| 规模 | 100/1,000/10,000/100,000 合成项目；1 KB/10 MB/1 GB/10 GB/50 GB 可丢弃文件 |
| NAS | 当前维护基线及目标 DSM/File Station 版本，逐项记录证据，不能按版本推断通过 |

50 GB 和外接卷等缺少空间、硬件或测试窗口时明确未执行；不以小文件或普通 App 浏览代替。性能数据与[验证原则中的合成基准](../quality/VERIFICATION_LEVELS_ZH.md)分开。

## 固定用例

保留以下 ID 便于关联缺陷。每项记录“通过/失败/未执行”；任何一步不符即失败，即使重试通过也保留首次失败。所有必选组合通过、清理完成且阻断缺陷关闭后，才能评估 `DEVICE_VERIFIED`，不能由社区报告或自动化自动升为 `STABLE`。

| ID | 操作与通过条件 |
| --- | --- |
| SIG-01 | 新测试用户安装：Gatekeeper 接受、可启动、签名/公证/票据有效 |
| SIG-02 | 检查内嵌扩展：存在、团队一致、系统实际识别 |
| SIG-03 | 创建全部共享映射：Finder 出现唯一入口，创建不下载正文 |
| SIG-04 | 创建单目录及非重叠映射：domain 唯一，不覆盖已有映射 |
| SIG-05 | 逐一移除并重启 App/Finder：入口消失，其他映射不受影响，无不可恢复孤立状态 |
| SIG-06 | 卸载重装：已明确删除的映射不意外恢复 |
| SHD-01 | App 创建后 Finder 枚举：双方可读映射及非秘密 runtime 更新 |
| SHD-02 | 覆盖安装：共享数据按 schema 策略保留，不重复 domain |
| SHD-03 | 受控 App Group 不可用：开始前禁用或提供恢复路径 |
| SHD-04 | 首次映射后读取：扩展可取得最小会话，安全存储无密码/OTP；不得导出正文 |
| SHD-05 | 两个测试 NAS 交替读取：会话和权限不串用 |
| SHD-06 | 退出 NAS 登录、会话失效、删除 NAS、移除最后映射：按策略清会话，不误删其他映射所需会话 |
| SHD-07 | 访问组或旧存储迁移失败：保留映射并提示恢复，不泄露凭据 |
| LIFE-01 | 关闭最后窗口：按产品设计后台运行，映射可用 |
| LIFE-02 | 显式退出 App 后读取：已有挂载由系统扩展继续处理，退出不改可用/暂停/共享会话；分别验证在线读取与完整缓存 |
| LIFE-03 | 系统终止扩展再浏览：可恢复，不重复 domain 或丢状态 |
| LIFE-04 | 重启 Finder、App、Mac：恢复状态，无泄漏任务 |
| LIFE-05 | 注销登录、睡眠唤醒：恢复未暂停映射，保留手动暂停 |
| LIFE-06 | NAS 重启、断网及网络切换：缓存与在线状态正确降级/恢复 |
| LIFE-07 | 下载中移除映射：停止新请求并可恢复清理，不以系统取消请求冒充传输已停止 |
| READ-01 | 五种规模首次打开：进度连续、大小与内容一致，不返回旧版本 |
| READ-02 | 10 MB/1 GB/10 GB 中途取消：分别记录 App Task 与实际网络/系统传输是否停止 |
| READ-03 | 中断再打开：按策略续传或重启，内容一致且不混用旧暂存 |
| READ-04 | 下载中退出 App、重启 Finder、断网恢复：继续或安全中止，无不可恢复任务 |
| READ-05 | 远端大小或修改时间变化：拒绝失效版本，不用旧内容冒充新内容 |
| READ-06 | 下载中占满空间：安全停止，不记录完整缓存或破坏既有内容 |
| VOL-01 | 选择各类缓存卷：合格可用，不合格在选择阶段拒绝 |
| VOL-02 | 下载中拔卷：安全降级，不在系统盘创建隐式第二映射 |
| VOL-03 | App 关闭或重启时缺卷再接入：稳定身份恢复，新内容重新执行容量准入 |
| VOL-04 | 改卷名及换不同身份卷：名称变化可恢复，不冒认另一卷 |
| VOL-05 | 缓存卷/系统盘分别不足：按实际缓存卷判断，不泄露卷标识 |
| VOL-06 | 触发 8 MiB 阈值容量下降：记录真实传输停止及 partial/完成记录 |
| VOL-07 | 清缓存/释放离线内容：只释放本地可重建内容，NAS 正文不变；区分物理释放与统计 |
| VOL-08 | 打开文件时触发 LRU：在用文件不被成功驱逐，固定内容不参与 LRU |
| DIR-01 | 四种目录规模：分页无重复遗漏，记录首屏/全量耗时、请求数及内存峰值 |
| DIR-02 | 滚动、切层后离开：枚举取消，无持续无界增长或 NAS 唤醒 |
| DIR-03 | QuickConnect 两类连接重复适用规模：记录类别与响应 |
| NAME-01 | 中英日文、emoji、NFC/NFD：安全显示或稳定失败，不静默改名回写 |
| NAME-02 | 长路径、大小写近似、空格、无扩展名/多点：异常项不影响其他可读项 |
| NAME-03 | 不可解码名称/无权限：其他项目可用，错误提供恢复动作 |
| NAME-04 | 枚举中新增/删除/改名：结果收敛，无永久重复或错误内容绑定 |
| OFF-01 | 固定文件/目录/映射：规划与空间预检后才请求正文，完成状态准确 |
| OFF-02 | 取消扫描/下载、部分完成后重启：区分完成项，范围与状态恢复 |
| OFF-03 | 完成后离线读取：已完成可读，未完成不冒充可离线 |
| OFF-04 | 父子重复固定再释放：覆盖关系正确，不释放仍被父级固定的内容 |
| OFF-05 | 临时缓存达到软上限：LRU 只释放临时项 |
| OFF-06 | 释放部分失败：只删除已确认释放的记录，可继续恢复 |
| UPG-01 | 旧版含映射/临时缓存/离线内容后原位升级：标识、位置、暂停和内容保留 |
| UPG-02 | App/扩展短暂版本不一致：安全失败或等待收敛，不损坏或重复状态 |
| UPG-03 | 升级后共享容器/会话/runtime：可读或明确恢复，不静默丢失 |
| UPG-04 | 候选新状态后按发布说明回退：记录旧版可读性，不删配置掩盖不兼容 |
| UPG-05 | 升级/回退后移除映射并重启：domain/本地状态/会话按策略收敛 |
| UPG-06 | 安装中断或首次恢复连续失败：可诊断重试，保留最后成功配置 |

补充故障：映射/domain 任一缺失、创建/移除中断、缺共享会话、孤立暂存和不可读 runtime，分别记录继续、回滚、隔离或重新认证；同步锚点裁剪/损坏/升级后须完整重新枚举，不能静默漏掉远端变化。

## 记录、清理与停止

每项只记用例 ID、状态、日期/时区、执行人稳定别名、App 版本/build/提交/安装包 SHA-256、系统/架构/DSM/套件版本、条件类别、用户可见结果、脱敏证据或缺陷编号、清理结果及未执行原因。证明内容一致只记算法类别与一致/不一致，不记测试文件校验值。

结束时停止新任务，等待任务结束；通过 App 释放本轮本地内容并移除映射，确认 Finder 入口消失；另行清理可丢弃 NAS 数据并只读复查，恢复卷/网络/空间。清理失败记“失败”和剩余影响，不记“未执行”。不得直接删除未知 File Provider、App Group、Keychain 或系统目录制造成功。

身份不一致、非测试数据受影响、缓存释放修改 NAS、落盘位置不明、升级覆盖唯一配置或无可用回退快照时，停止该批并按发布手册/测试快照恢复。证据中出现秘密或用户数据时停止采集并清理。现场生成物不得留存原始日志、数据库、响应、Keychain、真实路径或文件名；截图须先检查菜单栏/侧栏/标题，社区报告仍不接收截图。只保存必要脱敏结论，不另建运行流水归档。
