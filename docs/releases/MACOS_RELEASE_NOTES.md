## macOS 1.0.0

- 全新统一界面，支持浅色、深色与原生毛玻璃效果，保留系统窗口按钮。
- 重做文件、照片、聊天、下载、容器及虚拟机页面，统一导航和操作布局。
- 应用设置固定在侧栏底部；修复设置分类点击区域，加入软件更新入口。
- 修复聊天摘要缺失时误显示“没有消息”、文件权限读取和删除结果误报。
- 精简全应用重复说明，完善中英文文案，保留必要的操作与安全提醒。

本次仅发布 macOS 客户端，支持 macOS 14 或更新系统，安装包同时适用于 Apple 芯片与 Intel Mac。

- 首次安装：下载 DMG，将 LanStash 拖入“应用程序”。
- 后续更新：在 LanStash 菜单或“应用设置 → 岚仓更新”中检查更新。安装重启前请保存工作，并等待应用内及 Finder 文件传输完成。
- 更新仅替换客户端，不升级 NAS 系统或套件。
- 原先不支持在线更新的版本，需要先手动安装一次本版本。

Android、Windows、iPhone 和 iPad 不包含在此次发布中。NAS 功能是否可用取决于系统版本、套件与账号权限；兼容范围和已知限制请见仓库文档。

## English — macOS 1.0.0

- A unified interface with light and dark appearances, native frosted backgrounds, and standard window controls.
- Redesigned file, photo, chat, download, container, and virtual machine pages with consistent navigation and actions.
- App Settings now stays at the bottom of the sidebar, with improved category click targets and a software update page.
- Fixed misleading empty chat summaries, file permission decoding, and unconfirmed deletion results after successful deletion.
- Streamlined explanatory text throughout the app and refined English and Simplified Chinese copy while retaining essential warnings.

This release contains only the macOS client. Requires macOS 14 or later; the universal DMG supports Apple silicon and Intel Macs.

- First installation: open the DMG and drag LanStash into Applications.
- Future updates: check for updates from the LanStash menu or App Settings → LanStash Update. Save your work and finish app and Finder transfers before installing and restarting.
- Updates replace the client only, not the NAS system or packages.
- Versions without online update support need one manual installation first.

Other platforms are not included. NAS feature availability depends on the system version, installed packages, and account permissions. See the repository documentation for compatibility and known limitations.
