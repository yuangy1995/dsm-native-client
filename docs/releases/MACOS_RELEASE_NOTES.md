## macOS 1.0.16

- 文件上传统一在传输中心按批次查看，不再自动弹出重复详情；可展开查看文件、文件夹、跳过原因和错误。
- 上传中显示百分比与已传数据量，跳过项不计入待传数据量；完成后直接显示各项结果，支持清理已结束的记录。
- 修复照片已显示时底部仍持续转圈的问题；下载成功、失败或部分完成的提示均在 3 秒后自动消失，可直接再次下载。
- 修复文件图标视图多选，支持 Command 点选、Shift 连选和空白处拖动框选，双击正常打开项目。
- 加强文件图标与列表的选中反馈，浅色、深色和失去焦点时都更容易辨认，并修复侧栏样式影响文件列表高亮的问题。
- 修复切换多台 NAS 后部分设备无法显示存储容量的问题；返回时补齐未完成的读取，取消刷新保留该设备已有容量。
- 改善上传记录的状态与恢复提示，继续保留同名替换确认和中断后避免重复上传的保护。

## English — macOS 1.0.16

- View file uploads as expandable batches in Transfer Center, without duplicate detail windows opening automatically. Inspect files, folders, skipped items, and errors in one place.
- Show upload percentage and transferred data while running, excluding skipped items from the remaining workload. Display results when finished and clear completed records.
- Fixed the persistent spinner below an already displayed photo. Download success, failure, and partial-completion messages now disappear after three seconds, and you can download again directly.
- Fixed multiple selection in the file icon view, including Command-click, Shift-click, and drag selection from empty space. Double-click continues to open the selected item.
- Make selected icons and list rows easier to identify in light and dark appearance and when focus changes. Fixed sidebar styling overriding file-list selection highlights.
- Fixed missing storage capacity after switching between NAS devices. Returning to a device completes interrupted loading, and cancelling a refresh preserves its previous capacity reading.
- Clarify upload history and recovery messages while retaining replacement confirmation and protection against duplicate uploads after interruptions.
