## macOS 1.0.15

- Chat 语音消息可直接在消息内加载并播放，支持暂停、继续和重播；离开会话后自动停止。
- 系统已允许通知时隐藏开启通知按钮，返回应用时更新授权状态。
- 修复置顶消息加载失败，只显示当前会话的置顶内容，并改善错误提示。
- 修复本人语音消息的未读残留；打开会话定位到最新消息，阅读历史时新消息不抢滚动、不提前标记已读。
- 文件路径在空间足够时完整显示，空间不足时按需折叠，保留父目录菜单与键盘操作。
- 下载管理中缺失的下载速度、上传速度和剩余时间统一显示为 `--`。
- 调整 NAS 总览头部，操作紧凑排列，窄窗口自动换行，并同步中英文与浅深主题。

## English — macOS 1.0.15

- Play Chat voice messages directly in the conversation, with pause, resume, and replay. Playback stops when you leave the conversation.
- Hide the notification enable button when notifications are already authorized, and refresh permission status when returning to the app.
- Fixed pinned-message loading so results belong to the current conversation, with clearer error messages.
- Fixed unread counts remaining after viewing your own voice messages. Conversations open at the latest message, while new messages do not interrupt reading history or get marked as read early.
- Show the full file path when space allows and collapse only the necessary earlier folders, with accessible parent-folder menus and keyboard navigation.
- Display `--` for unavailable download speed, upload speed, and remaining time.
- Group NAS overview actions into a compact layout that adapts to narrow windows, with matching English and Simplified Chinese text and light/dark appearance.
