## macOS 1.0.18

- 移除照片页反复出现的“未完成的预览”入口与后台预览状态提示。
- 照片缩略图新增照片、视频、Live Photo 等类型标识。
- 优化时间线和相册选择：单击选择一张，Command 多选、Shift 连选，从空白处拖动框选，双击打开预览；不再默认显示所有多选勾选框。
- DSM 更新增加下载、安装确认、安装进度、等待 NAS 恢复和最终版本核验。支持的单机补丁可直接安装；需要额外提示、大版本或集群更新时引导到 DSM 完成。

## English — macOS 1.0.18

- Removed the recurring unfinished-preview entry and background preview status from Photos.
- Added media type badges for photos, videos, Live Photos, and other supported types.
- Improved timeline and album selection: click to select one item, Command-click to select multiple items, Shift-click for a range, drag from empty space to select an area, and double-click to preview. Selection checkmarks no longer appear on every item by default.
- Added DSM update download, installation confirmation, progress, reconnection status, and final version verification. Supported standalone patches can be installed directly; updates needing additional requirements, major upgrades, and cluster upgrades continue in DSM.
