# Android 已确认 UI 与交互规范

2026-10-11 用户确认[交互预览原件](android-approved-ui.html)，要求后续开发遵守该 UI，保留当前 Logo，并增加首页模块显隐。本规范是界面验收依据；功能范围见[五端矩阵](../progress/PLATFORM_MATRIX.md)，系统行为见[平台集成](../development/PLATFORM_INTEGRATION.md)。

## 固定视觉与布局

- 使用现有 `brand_logo` / `ic_launcher`，不替换、重绘或调整品牌标识。预览内图像直接来自原 Android 图标资源。
- 既有浅色背景 `#FAFAF8`、白色内容表面、主色 `#2455ED`；深色背景 `#11151B`、表面 `#171C25`、主色 `#A5BBFF`。正文与次级文字沿用 Material 对应颜色。
- 紧凑分组、列表和必要卡片，卡片圆角约 16—20 dp，输入/按钮约 12—14 dp，操作面板约 24 dp。沿用现有 Typography 和系统字体。
- 手机内容侧边距 20 dp，窄屏可收至 16 dp；按钮有效区域不少于 48 dp。产品不复制预览设备边框、模拟状态栏或手势条。
- 手机单栏/常用底栏；平板按可用宽度用原生侧栏，文件等并列列表与详情，窄窗回单栏，不缩小文字硬塞。
- 顶部为原 Logo、当前 NAS 选择、任务中心及全部功能。需要区分时显示账号，不在内容重复身份标签。
- 底栏默认首页、文件、照片、消息、设备，按权限临时过滤；全部已授权功能可达，不改用户固定项偏好。

## 首页自定义

默认顺序为以下四个模块；本轮增加显隐，不另增排序或新首页布局。

| 稳定标识 | 内容 | 权限与空状态 |
| --- | --- | --- |
| `quickActions` | 上传、浏览照片、新建下载等已授权快捷操作 | 无可用动作不留空卡片 |
| `activeTasks` | 进行中任务、真实进度与任务中心入口 | 无任务提供简短空状态，隐藏不停止任务 |
| `commonLocations` | 共享文件夹、收藏等真实常用位置 | 无文件权限不展示，授权但无内容时提供下一步 |
| `recentItems` | 当前 NAS/账号最近打开的真实记录；仅照片账号可用已取得的照片记录 | 不用示例文件或数量补空白 |

- 首页标题栏增加“自定义首页”，与搜索沿用相同按钮样式和点击区域。
- 手机底部面板、平板对话框，四个开关、恢复默认与保存；先编辑草稿，一次保存，取消不改偏好。
- 偏好只存稳定模块标识，独立于 NAS/账号/会话，默认全部显示。权限变化只过滤不可用内容，不更改开关。
- 允许全部隐藏，提供“自定义首页”空状态；全局导航、任务中心及全部功能仍可用。
- 不增加仪式式勾选，产品文案不暴露资源键、契约或能力探测术语。

## 页面与交互

| 场景 | 已确认形态 |
| --- | --- |
| NAS 切换 | 顶部选择器，面板列设备、必要账号、状态与选中标记，底部添加 NAS |
| 登录 | 原 Logo、已保存设备与独立表单；取消、OTP、错误恢复清晰，不重复应用名 |
| 文件 | 列表/图标/次级信息，面包屑合并搜索筛选；行菜单用操作面板，多选有统一批量栏 |
| 文件详情 | 手机独立预览，平板适宽并列；主要操作可达，不能挤压列表成不可读窄列 |
| 跨 NAS | 明确源文件/NAS，独立目标账号及可写目录；直接说明只读/未授权，阻止无权限提交 |
| 照片 | 照片/相册切换、日期分组、紧凑网格；实际多来源才显示“我的照片/共享照片”，对象动作按权限 |
| 消息 | 会话/未读/时间、独立聊天页和底部输入；附件/录音/操作用原生面板，归属固定 |
| 设备 | 连接摘要、账号与可用功能、NAS 应用、本机设置分组；无管理权限不伪造系统统计 |
| 可用功能 | 当前账号的可使用/未开放/失败及恢复，Android 系统权限单独分组 |
| 任务中心 | 全部/单 NAS、进行中/已结束，源目标、进度、适用操作；跨 NAS 显示两端 |
| 管理能力 | 设备/全部功能进入原生列表和分步表单，危险操作独立确认后果 |
| 应用设置 | 外观、语言、导航、传输、系统文件与通知，沿用语言资源和存储边界 |
