# 五端功能状态

本表是功能现状的唯一清单，按当前生产入口、执行器和接口适配核对。**已实现**表示源码中已有用户流程，不表示真实 NAS、设备或发布验收通过；**部分**必须同时说明缺口；**未实现**没有完整入口；**不做**不在当前产品范围。† 表示实现存在，但普通 Windows 包的相关写入口默认受保护。

iPhone 与 iPad 业务范围相同，分别使用单栏和适宽分栏。所有操作仍取决于当前账号、对象权限及实际接口；权限不足不等于客户端未实现。已知错误及设备步骤集中在[当前限制](KNOWN_LIMITATIONS.md)，系统行为见[平台集成](../development/PLATFORM_INTEGRATION.md)，接口细节见[API 目录](../api/README.md)。

## 默认保护与证据

Windows † 的准确开关来自 [DsmRepository](../../windows/src/LanStash.Infrastructure/DsmRepository.cs)、[Photos 安全模型](../../windows/src/LanStash.Domain/Photos)、[Office](../../windows/src/LanStash.Infrastructure/Features/Files/DsmRepository.OfficeEditing.cs)、[跨 NAS](../../windows/src/LanStash.Infrastructure/Features/Files/CopyMove/DsmRepository.FileCrossNasCopyMove.cs)、[NAS](../../windows/src/LanStash.Infrastructure/Features/NasAdmin)及[Cloud Files](../../windows/src/LanStash.App/CloudDrive/DesktopCloudDriveService.cs)。Cloud Files 先在设置中明确启用本次测试，再逐映射允许编辑、独立允许删除；这与 NAS 版本白名单无关。

源码入口与构建方法分别见 [macOS](../../apple/Apps/DsmMac/README.md)、[iPhone/iPad](../../apple/Apps/DsmMobile/README.md)、[Android](../../android/README.md)、[Windows](../../windows/README.md)。各端均有自动化和构建路径；当前提交是否通过以其 Checks 和可复现结果为准，不由另一平台或旧测试次数推定。正式版本与签名结果见[发布说明](../releases/MACOS_GITHUB_RELEASE_ZH.md)；当前源码不自动等于已发布版本。
