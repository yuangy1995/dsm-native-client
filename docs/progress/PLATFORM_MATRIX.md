# 平台功能矩阵

## 技术栈

| 平台 | 语言 | UI | 网络 | 安全存储 |
| --- | --- | --- | --- | --- |
| macOS | Swift | SwiftUI + AppKit | URLSession | 应用沙盒 AES-GCM 加密文件 |
| iPhone | Swift | SwiftUI + UIKit | URLSession | Keychain |
| iPad | Swift | SwiftUI + UIKit | URLSession | Keychain |
| Android | Kotlin | Jetpack Compose | OkHttp | Android Keystore |
| Windows | C# | WinUI 3 | HttpClient | Credential Locker/DPAPI |

Android 当前完成率、自动化快照、批次记录和真实验收缺口统一以[开发状态](STATUS.md)为准；本矩阵只维护各平台能力差异，避免复制滚动数字和批次日志。

Android 第 85 批差异补充：后台下载与照片备份来源现在必须同步持久化成功后才入队，超出 10,000 项扫描上限的照片来源会零部分入队并暂停；图片预览与媒体详情覆盖 EXIF 1–8，非嵌入全屏预览内容避开安全绘制区与 IME。Container 附属读取显式固定 v1、传播取消和认证失败，并只向总览投影稳定标识、名称与状态；VMM 运行态增加公开 `poweroff` 的独立危险确认。以上均待真实设备和专用 NAS 验收，其他平台语义未改变。

## 移动端产品范围说明

本矩阵同时记录“源码/契约现状”和“产品范围”，两者不得混用。Apple 移动端以 [iPhone/iPad 移动精选功能计划的范围矩阵](../development/APPLE_MOBILE_MACOS_PARITY_DEVELOPMENT_PLAN_ZH.md#33-iphone--ipad-产品范围矩阵)为唯一当前承诺：

| 标签 | 含义 |
| --- | --- |
| 核心 | 当前移动交付必须完成 |
| 受限 | 只交付专项矩阵列出的子集，未列出的桌面动作不构成缺口 |
| 后续 | 不进入当前开发 DAG，需独立决策后再开启 |
| 当前不做 | 本轮排除，并使用 Mac App、DSM Web 或系统 App 完成 |

下表 Apple 单元格中既有的“计划”“复用 Apple 契约”或“已接入”只表示历史进度/能力库存，不能覆盖上述产品范围；现存但被分类为“当前不做”的入口应在 Apple M0/M7 收口为不可见、只读或明确转交，并保证零危险请求。`PENDING_USER_VALIDATION` 只用于已经进入核心/受限范围的能力。Windows 仍按完整业务语义对齐；Android 继续以自己的专项计划和范围账本为准。
