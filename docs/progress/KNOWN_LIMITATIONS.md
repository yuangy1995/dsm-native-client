# 当前限制与待验收

功能是否实现只见[五端矩阵](PLATFORM_MATRIX.md)。这里记录尚需处理的问题和真实环境条件；历史出现过的问题不直接断言新版本仍会发生。

## 需继续处理的问题

| 问题 | 已知事实与影响 | 下一步 |
| --- | --- | --- |
| Photos 索引时间单位 | 官方字段为整数 Unix 毫秒，Windows 已修。Apple [Repository](../../apple/Packages/DsmNetwork/Sources/SynologyPhotosRepository.swift) 仍以秒构造 indexedAt；Android [Codec](../../android/app/src/main/java/io/github/qwertyuiop1995/dsmnativeclient/data/SynologyPhotosCodec.kt) 保留原数值，而 [日期分组](../../android/app/src/main/java/io/github/qwertyuiop1995/dsmnativeclient/photos/SynologyPhotosState.kt)和预览按秒换算。最近添加/元数据日期存在源码差异，原件与恢复身份也须一起审查 | 单独修复 Apple/Android 解码及身份比较，保留毫秒精度；旧错误恢复记录不得自动换算后认领或重放。这是源码工作，不是仅待真机 |
| macOS 跨 NAS 移动删源 | [WorkspaceModel](../../apple/Apps/DsmMac/Sources/WorkspaceModel.swift) 的传输中同名检查可返回零传输量，移动分支随后仍按顶层清单删源。源码存在需要修正核查的风险；没有真实数据丢失结论 | 修复前优先复制并保留源文件。用自造目录测试中途同名、目标变化和部分完成，确认每个删源对象都有完整目标依据 |
| VMM 保护清单兼容 | Windows 已支持 `protect_ids=[]`；非空编号不能当成空清单。Apple/Android 的现行保护读取也尚未专门处理这一返回形态 | 按官方页面只读证据补齐端点结构与各端解析，不猜测 get 参数，不开放未实现的保护管理 |
| 移动 Files 位置生命周期 | 两端只读/编辑主流程已有本机证据；2026-10-18 的 iPadOS 26.5 模拟器[云端记录](https://github.com/yuangy1995/dsm-native-client/actions/runs/39140870563)显示，连续移除重建位置时，选择器仍可读取已移除域并恢复禁用状态。2026-10-19 的 iPhone [协调日志](https://github.com/yuangy1995/dsm-native-client/actions/runs/39170662995)记录 Quick Look 读取占用约 78 秒；同日[索引日志](https://github.com/yuangy1995/dsm-native-client/actions/runs/39201230626/attempts/2)记录两次克隆设备清理时，系统自带和应用提供器的索引均超时，位置移除未在 90 秒内返回。真实设备上的读取占用和清理行为尚无完整验收 | 每个系统用例新建独立模拟器，实际本机写入与 NAS 回传分段验收；连续移除重建位置另需真实设备复验。保留文件协调锁、90 秒清理期限、回传期限、结果断言和只读权限 |
| 移动端模拟器启动卡顿 | 2026-10-21 的 iPadOS 26.5 [工作区测试](https://github.com/yuangy1995/dsm-native-client/actions/runs/39511613863/job/118933750230)中，合成空文件页持续显示加载中，系统报告主线程不响应；[模块测试](https://github.com/yuangy1995/dsm-native-client/actions/runs/39511613863/job/118933750221)中的聊天发送恢复也在重启后停留于文件加载页，主线程约 130 秒后恢复。两处诊断时模拟器的应用路径查询均超时，缺少调用栈，尚不能确定是运行环境还是客户端实现导致 | 使用[启动诊断](../../apple/Apps/DsmMobile/README.md)采集卡顿进程调用栈，复验文件页状态与聊天重启恢复；保留真实状态断言，不能只靠延长等待判定解决 |
| 移动端群聊创建界面回归 | 2026-10-21 的 iPadOS 26.5 [模块测试](https://github.com/yuangy1995/dsm-native-client/actions/runs/39511613863/job/118933750221)中，合成群名、两名成员选择与创建按钮可用检查已通过，单次点击后仍停留于表单；系统记录应用收到界面事件，未取得创建调用结果，原因尚未确认 | 保留创建结果断言，在完整回归中复验并核对点击与创建调用；不得通过重复提交群聊或跳过结果检查消除失败 |
| Windows 下载偶发加载失败 | 用户截图记录过失败；同会话的新旧读取均成功，尚未稳定复现。可选数字字符串/null 兼容已修，但不能声称它是唯一根因 | 新独立包持续刷新/重新连接；再次发生时提供模块、步骤、套件版本和脱敏错误 |
| 移动 Chat 最大字号附件操作 | 历史观察到群公告的附件预览/另存按钮裁切，未取得当前源码已修复的证据 | 在 iPhone 最大辅助字号及 iPad 窄窗复验实际按钮区域、滚动与操作；先确认是否仍存在 |
| Android 照片布局退出 | 历史合成场景一次 Compose 布局崩溃未稳定复现，后续定点与整组通过不证明原根因已解决 | 使用当前包在深色、大字、混合选择与页面返回场景复验；只记录异常类别和可重复步骤 |

上述问题不授权更改用户真实数据。已完成修复并具备针对性证据后删除对应条目，不在本页追加逐轮流水。

## PENDING_USER_VALIDATION

这是带操作条件的待办，不是验证等级；未实现/不做的功能不放入此表。所有写测试使用可丢弃资料，受保护入口须先明确专项测试范围。

| 范围与前置条件 | 操作 | 预期结果与影响 | 允许回传的失败信息 |
| --- | --- | --- | --- |
| 登录：普通/管理账号，直连/QuickConnect及可恢复测试证书 | 登录/OTP、重登、换账号、撤销权限、证书变更 | 不串账号；认证失败有恢复入口，错误信任不继续 | App/系统/DSM/套件版本、连接方式与权限类别、步骤和错误类别 |
| 文件/Photos/Chat/下载/NAS管理：专用测试对象，先只读后单项写 | 正常操作、权限拒绝、提交前后取消、断网、重启、另一客户端修改同一测试对象 | 只作用于确认目标；未知不重发，已完成事实保留，失败不冒充空内容或成功；Photos先处理上述单位差异 | 操作阶段、合成数量、实际/预期结果；不发正文或原始响应 |
| Office：六种合成格式及实际 Office/WPS/Apple 编辑器 | 不修改退出、连续/原子保存、并发改原件、断网、编辑器异常结束 | 未修改零上传；冲突停止覆盖，保留本机副本；公开 Upload 不能提供跨客户端原子锁 | 格式、编辑器版本、保存顺序与状态；不上传真实文档 |
| Finder/Files/Cloud Files：正确签名/共享权限，独立本地根与可丢弃 NAS 目录 | 首次启用、浏览/缓存、分别允许编辑和删除、锁屏/进程结束、移除位置、升级/回退 | 根保护、原账号绑定、未知恢复和未保存副本保留；移除/释放缓存不等于删除 NAS 文件 | 平台、签名类别、阶段、错误类别；步骤另见[云盘验收](../compatibility/DESKTOP_CLOUD_DRIVE_RELEASE_ACCEPTANCE_ZH.md) |
| 移动后台与分享：两类设备、系统权限、可中断测试传输 | 前台开始后切 App/锁屏、拒绝系统资格、取消、系统终止，再回原账号 | 只处理原执行；时间到期停止后项、保存未知结果，不自动重传或删源；不承诺终止进程后继续 | OS/设备类别、授权结果、前后台顺序、任务状态 |
| 控制台/音视频：实际 VMM、WebView2或系统媒体组件、麦克风 | 连接/断开/手动重连、播放录音、拒绝权限、来电/耳机变化 | 不泄露会话，不自动录音或重放输入；认证/证书错误停止 | 组件/设备/套件版本、动作顺序与脱敏错误 |
| 无障碍与显示：中英文、浅深色、最大文字、高DPI、键鼠/触控/读屏 | 各模块加载/空/筛选空/错误/正常，弹窗滚动、焦点、返回与降低动态效果 | 标签与操作可达，真实边界不裁切，确认对象不漂移 | 具体控件、窗口/字号设置与脱敏截图 |

不回传密码、OTP、Cookie、SID、SynoToken、DID、私钥、真实主机/账号/路径、消息或日志正文、HAR/PCAP及恢复数据库。系统注册、物理 ARM64、真实 NAS、签名和辅助功能未执行时，不能用构建或合成测试替代。
