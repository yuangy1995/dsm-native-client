# 桌面端本地磁盘挂载与按需缓存

## 当前范围与平台实现

macOS 用户界面称“本地磁盘挂载”，内部 `DesktopCloudDrive` 名称保持不变。macOS 使用 Replicated File Provider Extension，Windows 使用 Cloud Files API 同步根；在系统文件管理器展示 NAS 位置，不要求独立 `/Volumes` 卷或盘符。文件内容以 NAS 为准，本地缓存不是备份。

| 能力 | macOS | Windows |
| --- | --- | --- |
| 映射范围 | 指定共享/子目录，或当前账号可见的全部共享 | 同左；只列有权共享，不暴露 DSM 系统根 |
| 默认状态 | 只读，按需加载元数据/文件，用户可离线保留 | 同左 |
| 编辑与上传 | 指定文件夹和全部共享可按映射启用；文件保存、上传、新建目录与范围内移动/改名 | 已接入保存、新建、移动/改名及全部共享内部路径 |
| 删除 | 必须先启用编辑，再单独确认允许；未知结果只核查 | 同左，已接删除与恢复界面 |
| 跨共享移动 | 当前 macOS 映射写范围仍拒绝 | 已有全部共享内部 MoveRename 路径；目标权限和根保护不变 |
| 系统验收 | 正式签名、App Group、共享 Keychain 与 Finder 待用户验证 | Explorer 回调、外接卷、重启、安装升级等真实环境待用户验证 |

映射根和共享根不可修改或删除。关闭编辑同时撤销删除授权；不能把缓存释放、移除映射或移除任务记录解释为删除 NAS 文件。

2026-10-03 修复已开启编辑/删除仍只读的问题：普通文件的空挂载类型不再被当成特殊挂载；权限变化更新 Finder 元数据，并使旧目录/工作集增量锚点失效，沿用系统重新枚举。未改变内容版本、文件身份、持久化格式或权限保护。源码、自动化和正式签名后的待验步骤见[专项账本](MACOS_MOUNT_WRITABILITY_FIX_20261003_ZH.md)。

## 架构与数据边界

- 复用 File Station 官方能力、`DsmCore` 映射/缓存/日志模型及现有平台协调器，不新建私有文件系统协议。请求语义见[文件 API](../api/reference/files.md)。
- 每映射绑定 profile、远端根、用户选择范围、缓存位置与最小必要会话；普通 App 密码不写入 Extension 共享会话。缺扩展或共享容器时不假装支持系统挂载。
- 目录快照与变化日志绑定 generation/revision；慢扫描以 CAS 校验，失效/损坏/裁剪时重新枚举，不发布倒退或虚假删除。working set 与根目录 anchor 分离，避免无条件扫描完整 NAS。
- 缓存卷和临时空间先检查；按需读取校验 Range、总长、内容版本，固定和使用中的文件不被自动释放。远端版本变化不能拼接旧分片。
- 写回使用稳定目标、基线、独立快照、确认和操作身份。NAS 回执与最终回读分别处理，冲突保留本机版本；公开 Upload 没有原子条件替换，不能保证跨客户端并发保存不覆盖。
- 删除日志保留操作类型、递归范围、恢复意图及退役项目身份；旧记录默认为原有保存语义。未知删除只核查，不重复提交、不伪造撤销、不自动重建原文件。
- Windows 日志 v10 向后读取，新格式对旧包保留并拒绝；macOS 增量字段保持既有兼容。本文整理不修改格式、权限或注册方式；后续变更须给出迁移/回滚并获得授权。

## 生命周期与故障恢复

关闭主窗口保留后台与映射；明确退出按现有生命周期处理在途任务，不用删除映射模拟安全退出。会话过期、证书变化、网络中断、缓存卷丢失或权限撤销时停止相关操作，保留恢复资料并给出下一步。

写入提交前可取消；提交后取消只能表示请求取消，最终效果继续核查。关闭编辑/删除不抹掉已提交未知操作，回退旧版本前先处理未完成操作并保留可恢复快照。释放缓存前确认数据已保存且无未解决写入。

## 非目标

不实现双向合并、多人协作锁、任意离线编辑、独立文件系统驱动或 NAS 全库预下载；不承诺远端变化实时推送。内置 Office 本机副本编辑是独立 App 流程，不依赖 Finder 扩展，见[macOS 使用说明](../../apple/Apps/DsmMac/README.md)。移动端不复制桌面常驻/挂载架构。

## 验证与发布条件

源码与合成检查覆盖会话隔离、映射事务、空间与缓存保护、Range 连续性、日志恢复、CAS、逐阶段写回、取消和未知结果；正式系统验收集中在[发布与升级验收](../compatibility/DESKTOP_CLOUD_DRIVE_RELEASE_ACCEPTANCE_ZH.md)，性能口径见[基准方案](../quality/DESKTOP_CLOUD_DRIVE_BENCHMARK_ZH.md)。

本机临时签名包移除 File Provider 扩展，只用于主 App 功能验证；签名完整性不能替代共享 Keychain、系统注册或 Finder 结果。高风险系统入口继续受用户授权、权限及能力保护。

`PENDING_USER_VALIDATION`：正式签名/受控 Windows 包、专用 NAS 和可丢弃映射下，分别测试只读、编辑、删除授权、跨范围拒绝、冲突、断网、重启、缓存盘拔出、升级/回退。预期旧内容保留、未知不重放、根不受影响、状态可恢复。反馈仅含用例 ID、平台/版本类别、步骤、结果与脱敏错误。
