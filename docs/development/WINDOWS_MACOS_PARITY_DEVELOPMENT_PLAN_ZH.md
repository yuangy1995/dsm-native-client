链接固定 Task v3，任务文件按有无目录使用 v2/v1；实际发送内容先冻结再取摘要，原文件改名、换目录或换密码不能解除同来源未知保护。空成功回执只表示请求被接受，未给编号时不认领相似任务。目录和密码保留合法原值，密码含换行/空字符时拒绝；接受、任务状态与文件完成分别展示。

单项控制、任务移除、批量控制与 Task.edit v2 保存位置共用 DownloadActions-v1 队列。写前用户加密保存，跨动作互斥，单项完成后不因其他项未知而重放或冻结已完成目标；未执行项只能明确继续或取消。移除必须同时具有本次唯一匹配的接受回执与完整列表消失证据，失回执后消失仍未知。保存位置只确认字段更新，不推断文件搬迁。“结束并移出未完成文件”默认关闭，合成宿主专门启用测试，不进入生产默认菜单。

设置按明确布尔管理权限、字段实际存在性及用户差量发送；每个分区前重读当前权限和改变字段的原值。HTTP/FTP 只有原值均存在且一致才允许共同修改；不补 false/0、不重写未改字段、不要求 File Station 浏览权限来证明设置权限。常规与计划分开保留结果；未知只查询，未开始分区不自动续写。公开 Download Station 错误独立解释，402 为目录拒绝、405 为无效操作、407 为设置失败，未知错误不能解除保护。

已完成独立集成及只读对抗复核：并发控制/移除、任务身份变化、字段缺失/类型错误、权限撤销、回执丢失与持久保存失败、重新连接/QuickConnect 路由变化、跨账号迟到结果和残余批次均有合成覆盖。真实 NAS 不在本机验证范围；具体环境、步骤、脱敏反馈与影响范围记入本波验证历史。最终 452 项下载/受保护存储/连接/证书联合回归通过，中文与英文整组各 68 项、布局/位置编辑及确认生命周期专项补验通过，生产 x64/ARM64 均零警告错误；4798 对双语资源与硬编码、请求/fixture、生成目录和文档门禁通过。单项移除确认固定原任务/连接并随页面关闭，确认及完成文案不推断文件结果。具体阶段、真实命令和待验步骤见[W5 验证历史](../archive/2026-h2/RELEASE_VALIDATION_HISTORY.md#2026-10-16-windows-w5-download-station未提交工作区)。W6–W9 继续，最终测试包尚未生成。

## Office 本机编辑的新增语义基线

Windows W3 已接入六种 Office 扩展名、系统进程外预览、缺少组件后的本机副本入口，以及“选择副本 → 默认或自选应用打开 → 稳定保存自动回传 → 原生状态/文档管理”的完整本机流程。沿 [Microsoft 预览机制](https://learn.microsoft.com/en-us/windows/win32/shell/preview-handlers)，只激活 LOCAL_SERVER，依次使用组件支持的 Stream/File/Item 初始化；不改注册或系统隔离。关闭预览和隐藏窗口保留工作区编辑，退出先保护在途保存并保留副本。继续、另存、结束和冷恢复均绑定原 NAS/账号；已有结束记录不遮住当前会话。

新增独立 OfficeEditing-v1 用户加密最小记录，复用既有 File Station 上传、实际权限、接受回执和完整内容回读。文件身份/时间检测原子替换，稳定两秒后冻结独立快照；未改零网络写，远端元数据/MD5 变化暂停覆盖，未知只读、不按相同内容补造回执。编辑目标与上传、移动、回收、归档和跨 NAS 删源共用现有互斥，初始化预检也先登记；云盘同步根不能作为编辑副本位置，同目标不能同时由云盘写回接管。公开 Upload 无原子条件覆盖，`OfficeAutomaticUploadEnabled` 默认关闭；普通包仍可预览和打开副本。

当前 W3 为 IMPLEMENTED / AUTOMATED / BUILD_VERIFIED：752 项相关 xUnit、中文及英文窄窗口/侧栏循环各 32 项、当前生产 x64/ARM64 均通过。真实临时文件测试修复了便携版缺少包身份时的预览目录错误；COM 回调类型已通过本机接口查询，合成预览不代表真实 Office 组件已加载。独立集成及只读对抗复核、真实命令、失败与修复阶段、具体 PENDING_USER_VALIDATION 条件见[验证历史](../archive/2026-h2/RELEASE_VALIDATION_HISTORY.md#2026-10-16-windows-w3-office-预览与本机编辑未提交工作区)。不修改 NAS 契约、其他四端、签名、权限或依赖。W4–W9 和最终双架构测试包继续。
