# iPhone 与 iPad 完整业务对齐实施计划

本页是 2026-10-04 用户确认的 M0→M8 唯一实施主线，取代旧“移动精选／只读管理”范围。两种设备业务范围一致：iPhone 使用单栏导航和分步表单；iPad 按可用宽度提供分栏、并列详情、键盘和拖放。macOS 是业务与安全语义参考，不照搬悬停、右键、菜单栏和常驻进程。计划纳入不代表已经实现或验证。

## 固定基线与授权

- 2026-10-04 用户补充：移动端尚未发布，M0–M8 及后续移动工作统一按开发阶段处理。采用当前数据结构，不为旧开发数据保留迁移、兼容模式或版本回退；无用旧代码直接删除。先前各切片关于旧开发版本读写兼容的设计由本条取代。保留当前操作的账号隔离、持久恢复和防重复提交；不以清理旧数据为由自动操作 NAS 真实数据。已发布 macOS 的实际调用与存储仍需单独核实和回归。
- macOS 1.0.15（25）正式基线为 `e3bd3480973b325fb76c75783c2f26b682e64f5f`，标签 `macos/v1.0.15`；[正式工作流](https://github.com/yuangy1995/dsm-native-client/actions/runs/37141445406)。正式流程及公开双架构附件/更新源回读已通过，结果记入[验证历史](../archive/2026-h2/RELEASE_VALIDATION_HISTORY.md)。
- 允许渐进重构、必要共享逻辑提取和 macOS 引用/平台适配调整，保持其用户行为及数据兼容；不扩展无关桌面功能。
- 保持 `main`、现有主 App 身份、iOS/iPadOS 17、SwiftUI、Swift 6、英语与简体中文、登录配置格式。
- 用户授权必要的隔离测试及模拟器操作，禁止影响 NAS 真实数据；官方已登录页面只作必要只读核对。TestFlight 和移动正式发布不在本次发布范围。
- 共享目标不增加第三方依赖；恢复队列独立版本化，不迁移旧配置、不存明文凭据；回滚停用新增入口并保留原配置。M8 的扩展身份、共享权限及存储在实施前列明必要性、影响和回滚。

## 证据与安全门

实现、自动化、目标构建和真机证据分别记录。`PENDING_USER_VALIDATION` 只是有明确步骤的设备待办；静态源码断言、合成网络结果、系统 UI 测试和真实 NAS 行为不能互代。未开发能力不得写成仅待实机。

公开与内部写保留实际权限、稳定目标、明确确认、防重复、未知结果只查询和最终状态核对。未验证且可能导致数据丢失、凭据泄露、越权或不可逆副作用的入口单独受保护，不阻塞无依赖切片。契约只维护在[API 目录](../api/README.md)，变更同步五端影响，不改 Windows/Android 实现。

## 顺序、所有权与质量门

本切片以 Mac `WorkspaceModuleAccess.swift`、`WorkspaceModel` 与设置页为入口语义证据：默认关闭可选功能，已保存选择与当前账号授权取交集；失败、退出、换账号和权限撤销不得沿用旧授权。iPhone 动态标签、iPad 动态侧栏均以文件和 App 设置为固定入口，活动中心移入文件工具栏。只读复用已有 `DsmDesktopAppPrivilegesService`；照片使用已记录 Synology Photos `access()`，不能以旧 File Station 图库权限代替。保留现有设备偏好键与字符串数组格式，缺省改为空集，已显式保存的选项保留；不迁移登录配置，无新增持久化结构。单一修改范围为移动 AppShell/Session/Settings、Debug 合成场景、对应测试、双语资源与工程。Mac、Windows、Android 行为及 NAS 写权限不变；不是新增私有 API 发现。两端各 702 项单元与七项权限/导航实际 UI（包含独立中文流程）已通过；另有目录上传重启、Office 活动恢复回归。共享测试及 Mac 双架构构建通过，具体命令与修正记录见[验证历史](../archive/2026-h2/RELEASE_VALIDATION_HISTORY.md#2026-10-04-移动默认模块与账号权限导航)。


权限刷新在登录、回到前台、打开设置和主动刷新时执行，结果整体替换；证书错误/取消不追加照片探测。关闭或撤销当前模块回到 App 设置，已保存偏好不被授权结果覆盖。旧账号迟到结果及尚未开始的已取消任务不能写入新连接状态；照片授权读取使用独立 Repository 实例，避免清空正在使用的预览与对象权限缓存。设置有加载、无候选、读取失败及正常状态；语言资源完整同步，系统“更多”沿用系统语言。

`PENDING_USER_VALIDATION`：iPhone/iPad 真机与已授权普通/管理员账号，首次登录确认仅文件与 App 设置，逐项开启后检查对应入口；换账号、管理员撤销应用权限、重新登录及前后台切换后刷新，确认列表只含当前授权且旧页停止。断网/证书变化后应提供连接恢复或刷新入口，不显示旧授权；文件和本机设置仍可到达。真实 DSM/套件权限差异、VoiceOver、大字号与外接键盘尚待验证，仅回传 App/OS/DSM/套件版本、脱敏步骤和错误类别，不提供账号、主机或原始权限响应。此切片不新增 NAS 写接口，不将源代码或模拟器结果提升为真实环境验证。
